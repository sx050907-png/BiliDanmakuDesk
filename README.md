# 弹幕同行 · BiliDanmakuDesk

**作者：霜星** · Windows 桌面工具 · 当前版本 **0.13.0**

把 B 站弹幕配到自己的本地电影上，边看画面边核对时间，再导出 ASS 用 PotPlayer 播放。

[下载 Windows 便携版](https://github.com/sx050907-png/BiliDanmakuDesk/releases/latest) · [作者与版权](AUTHORS.md) · [源码构建](BUILDING.md) · [第三方组件](THIRD_PARTY.md)

## 开始使用

1. 从 Releases 下载 `BiliDanmakuDesk-0.13-Windows-x64.zip`，解压整个文件夹后双击 `BiliDanmakuDesk.exe`。
2. 粘贴 B 站 `ep / ss / BV / av / b23.tv` 链接，解析、选集、下载弹幕；也可导入 XML 或已保存的项目。
3. 选择本地电影，打开「电影与弹幕核对」。在画面里调整时间与弹幕显示。
4. 点击右下角「保存调整」，返回主界面，再导出 ASS 或调用 PotPlayer 播放。

请保留 EXE 同目录的 `_internal` 和 `licenses`；不能只复制 EXE。

## 电影与弹幕核对

| 功能 | 操作 |
| --- | --- |
| 播放／暂停 | 单击电影画面或空格 |
| 快进／后退 | →／← 跳转 5 秒；按住 → 临时 3 倍速，松开恢复 |
| 画面全屏 | F11；Esc 退出。鼠标静止约 3 秒隐藏控件 |
| 显示弹幕 | 开关临时隐藏／开启，不影响导出内容 |
| 倍速菜单 | 点击展开，再次点击收起；选倍速或点外面也收起 |
| 撤销／重做 | Ctrl+Z／Ctrl+Y |
| 时间线缩放 | Alt＋滚轮；横向滚动条查看前后，点击「全片」恢复 |

「弹幕显示设置」可调整字体、字号（20–64）、显示区域（20–100%）、**不透明度（1–100%）**、滚动时间（3–20 秒）和屏蔽词。数值越小越透明，100% 完全不透明；可输入百分比或拖动滑块。应用设置会更新当前画面，保存后才用于主项目及导出。

区域 50% 表示使用上半屏，100% 表示全屏。滚动时间越小速度越快。屏蔽词每行一个，包含任意词的整条弹幕隐藏，英文不区分大小写；删除屏蔽词即可恢复。原始 XML 与项目保留原始弹幕。

## B 站删掉了一段、本地电影保留了，怎么办？

这段没有对应的 B 站弹幕，需要让后面的弹幕等这段播完再接上。

打开「选择 B 站删减片段」，在本地电影进度条上选出这一段的开始与结束，点击「按这段时长后移后面的弹幕」。前面的弹幕不变，后面的整体后移。

时间线显示橙色起止标记、连接色带、起止时间和状态。**已应用区间可直接拖动，无需再打开对话框**：拖两端修改时间，拖中间移动整段。Alt＋滚轮放大，Shift 精调；松开后更新，一次拖动对应一次撤销；Esc 取消正在进行的拖动。保存后重新打开项目也能看到标记。

例如本地 10:00–10:30 的画面被 B 站删掉，选出这段后，后面的弹幕会后移 30 秒。之前已经出现的弹幕可能仍在滚动；工具不生成原弹幕池没有的内容。

## 声音校准与范围

「从 B 站链接自动校准」分析正常可访问的参考音轨，与本地电影的声音匹配；可能只取得公开试看的前 6 分钟。无需自己录制片段，但结果只代表匹配到的时段，**不会自动识别整片所有删减**。

声音匹配需要 FFmpeg／ffprobe；源不可访问、受 DRM 保护、配音不同或素材不适合时会提示失败。工具不提取浏览器登录信息。下载的是接口当前返回的弹幕池，不保证包含全部历史弹幕。

源码运行与 Windows 构建见 [BUILDING.md](BUILDING.md)。播放器 DLL 不写进 Git 历史，通过带 SHA256 校验的下载脚本获取。仓库提供 Windows 自动测试；本地 31 项测试通过，实机验证范围见 [VALIDATION.md](VALIDATION.md)。

`示例/演示弹幕.xml` 是原创演示数据，不对应任何影片。仓库和便携包不包含电影、用户配置或从 B 站下载的电影弹幕池。
